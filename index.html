Privacy Policy — Download Security Agent

Effective Date: October 20, 2026 • Applies to: Google Chrome Extension & Local Security Agent

Core Privacy Commitment: Download Security Agent is an on-device, local-first security platform. Your downloaded files, browsing behavior, URLs, and file payloads are analyzed strictly on your local machine. We do not collect, transmit, store, or sell any personal data to remote servers or third-party cloud infrastructure.

1. Overview & Single Purpose

Download Security Agent is an endpoint security system consisting of a browser extension and a local desktop host daemon. Its sole purpose is to provide real-time browser download inspection and malware defense using local heuristic, signature, PE structure, and machine learning models.

2. What Information We Process

The extension monitors browser download events strictly to inspect files for security threats. Here is the exact data processed during an inspection:

  • Download Metadata: Filename, local target file path, MIME type, file size, and download source URL (used solely for local URL-reputation lookup and local audit logging).
  • File Binary Payload: Read locally from disk by the on-device agent to compute cryptographic hashes (SHA-256, SHA-1, MD5), inspect PE headers, check Authenticode digital signatures, evaluate YARA-X rules, and scan with the local ClamAV daemon.

Zero Cloud File Uploads

Unlike cloud-based antivirus software, the binary contents of your downloaded files are never uploaded to external cloud servers. All 11 inspection engines execute entirely inside your local operating system environment.

3. Chrome Extension Permissions & Technical Justification

In adherence to the Chrome Web Store Minimum Permissions Policy, Download Security Agent requests only the minimum set of permissions necessary to function:

Permission Technical Purpose & Justification
downloads Allows the extension to detect newly initiated downloads (chrome.downloads.onCreated), temporarily pause dangerous downloads, and resume or cancel them based on scan verdicts.
nativeMessaging Allows the extension to communicate via standard input/output (stdio) with the local host security agent (com.downloadsecurity.agent) running on your computer.
storage Used strictly to store local user preferences within the browser (such as auto-quarantine preferences, notification settings, and dashboard UI theme states).
tabs Allows the extension to open a local threat warning or SOC Forensic Incident Dossier tab when a high-risk or malicious download is intercepted.

4. Third-Party Services & Data Sharing

We strictly respect user privacy and adhere to the Chrome Web Store Developer Program Policies:

  • No Selling of Personal Data: We do not sell, rent, monetize, or trade any user data or download logs to data brokers, advertisers, or third parties.
  • No Targeted Advertising: We do not serve advertisements, build user behavioral profiles, or track browsing history across websites.
  • Optional Threat Intelligence Lookups: If a user explicitly configures an external API key (such as VirusTotal or AlienVault OTX) in their local settings, only the cryptographic file hash (e.g. SHA-256) is queried against that provider's public API. No personal identifiers or file payloads are sent.

5. Local Data Storage & Retention

Inspection logs, scan verdicts, and quarantined file metadata are stored exclusively on your local workstation in:

%LOCALAPPDATA%\DownloadSecurityAgent\history.json

Users have complete ownership over this data and may clear their scan history, purge quarantined files, or delete the data directory at any time directly through the Desktop Dashboard settings or by deleting the file from disk.

6. Security of Your Data

Communication between the browser extension and the local security host occurs via Chrome's native messaging protocol, strictly bounded by the Chrome operating system sandbox. Local WebSocket IPC used by the desktop dashboard binds exclusively to the loopback interface (127.0.0.1) and is protected by local authentication tokens to prevent unauthorized cross-origin access.

7. Children's Privacy

Our extension and desktop application do not knowingly collect or solicit any personal information from children under the age of 13.

8. Policy Updates

We may update this Privacy Policy from time to time to reflect improvements in our scanning capabilities or changes to browser security standards. Any changes will be posted to this page with an updated "Effective Date."

9. Contact & Inquiries

If you have any questions, feedback, or inquiries regarding this Privacy Policy or the security architecture of the Download Security Agent, please contact our support team through the official Chrome Web Store extension support tab or your designated organization administrator.
